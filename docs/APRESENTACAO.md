# Como apresentar o case sem internet

1. Mostre `fase/01-pipeline-verde-bug`: build e testes verdes, mas pedido confirmado sem reserva.
2. Compare com `fase/02-requisito-e-estados`: qual invariante faltou?
3. Mostre `fase/03-teste-vermelho`: dois novos testes de falha expõem o bug.
4. Mostre `fase/04-invariante-corrigida`: mudança local de domínio, testes verdes.
5. Visite `main`: contrato OpenAPI, sinais de negócio, cinco cenários, timeline e CI/CD.

**Pergunta para o público:** o que seu pipeline não consegue verificar porque ainda não foi especificado?

A demo é fictícia; não representa empresa, cliente ou incidente real.
