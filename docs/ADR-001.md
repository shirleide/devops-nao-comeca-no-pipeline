# ADR-001 — Domínio antes do pipeline

**Decisão:** manter uma função de domínio que concentra a transição para CONFIRMED.

**Contexto:** uma autorização de pagamento, isoladamente, não garante a reserva de estoque.

**Consequências:** contratos honestos, estados intermediários, testes para falhas e observabilidade de invariantes.

**Limitação:** este case usa integrações simuladas e não implementa transações distribuídas, idempotência persistida ou compensações reais.
